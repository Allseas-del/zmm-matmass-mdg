▸ Details
  • The app runs inside the Fiori launchpad of the same SAP system; requests use your launchpad session. No password is entered or stored.
  • Service path: /IWFND/V4_ADMIN → service group of the Product API → "Service Test". Editable in case the path differs.
  • sap-client: leave empty to use the client of the launchpad session.
  • V2 service: only for "Create" without "Send product number": API_PRODUCT_2 (V4) cannot assign an internal number, API_PRODUCT_SRV (V2) can.
  • Authorization: S_START for the service group (R3TR G4BA), S_SERVICE for the V2 service, plus the material master authorizations; see the design document, chapter 8.
2

File

Load a filled template, or read products from SAP into the same template.
Example template
Example: Migration Cockpit template "Product" (S/4HANA 2023) with one HAWA and one SERV product, plant/valuation area NL10, 2 storage locations for the HAWA product. Open it in Excel, replace the example rows and save as XML Spreadsheet 2003.
The result is the same "Product" template as with Load file (same sheets and columns), filled with the values from SAP. Columns can be hidden; they stay in the file.

Define scope (fields)

Keys (PRODUCT, WERKS, LGORT, BWKEY, MEINH …) are always read and always visible.

Select products

Every field of the template can be a criterion (fields the service marks as not filterable are not offered). Same field: OR; fields of the same sheet: AND on the same row (e.g. plant NL10 and MRP type PD); different sheets: AND per product. Exclude removes the products that have a matching row. Values as in the template (ISO units, X for yes, dates YYYY-MM-DD).

Options

Read in packages of "Products per $batch", "Parallel requests" at a time (Execute → settings). Values come from SAP as they are; in mode Change only the cells you change afterwards are sent.
